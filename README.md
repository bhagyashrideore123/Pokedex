⚡ Pokedex

A responsive web application built using JavaScript and external APIs to display detailed information about various Pokémon.

🔍 About The Project
Pokedex is an interactive web application designed to fetch, process, and display Pokémon data dynamically.The main goal of this project was to practice:
Fetching data from external APIs using JavaScript (fetch, async/await)
Binding and rendering dynamic content with HTMLtemplates
Handling DOM manipulation efficiently
Structuring modular CSS files and building a responsive layout

🛠️ Built With
HTML5
CSS3 (with organized modular stylesheets)
JavaScript (ES6+)
Pokémon API

✨ Highlights
Fully responsive design optimized for various screen sizes
Dynamic data fetching from an online Pokémon API
Interactive UI elements including navigation and detailed views
Clean and structured template rendering using JavaScript
